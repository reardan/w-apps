# Win browser documentation

Win is a browser to be implemented in W, using W's parser tooling, native UI framework, graphics, and networking libraries.

Start with the [implementation plan](implementation-plan.md). It defines the reusable foundations, browser architecture, initial compatibility scope, and milestones from a native window to scripted pages.

The [foundation readiness assessment](foundation-readiness.md) records the current W pin, verified capabilities, remaining integration work, and test results. The base libraries are sufficient to start the native shell and static-page engine.
