Welcome to Win

A small browser, built with W from the window to the words.

This is a working static document viewer. It parses HTML, measures real font glyphs, wraps text, and paints the page using the W UI framework.

Take a look around

  • Read an article with headings, lists, emphasis, and a long page to scroll.
  • Jump to the details below without fetching this document again.
  • Open a local HTML path or enter a full http:// or https:// address above.

What works in this version

Links, back and forward, reload, stop, scrolling, resizing, UTF-8 text, and basic inline text styling. Fetches happen outside the UI process so a slow server does not lock the window.

Use Ctrl+L to select the address. Press Enter or Go to navigate.

Still to come

Stylesheet cascade and full CSS layout, image display, tabs, forms, and page JavaScript. This version does not execute scripts or load linked stylesheets.

Win is a beginning. The next milestone is a richer document engine.
