Welcome to Win

A small browser, built with W from the window to the words.

This is an interactive document browser. It parses HTML, measures real font glyphs, wraps text, and paints the page using the W UI framework.

Take a look around

  • Try the interactive demo with a counter, form, stylesheet and image.
  • Read an article with headings, lists, emphasis, and a long page to scroll.
  • Jump to the details below without fetching this document again.
  • Open a local HTML path or enter a full http:// or https:// address above.

What works in this version

Tabs, links, history, stylesheet cascade, box layout, PNG/JPEG images, forms, and bounded page JavaScript. Fetches happen outside the UI process so a slow server does not lock the window.

Use Ctrl+L to select the address, Ctrl+T for a new tab, and Ctrl+W to close it. Press Enter or Go to navigate.

Still to come

Broader CSS and JavaScript compatibility, additional image formats, downloads, cookies, and persistent sessions. The supported feature set is documented alongside the browser.
